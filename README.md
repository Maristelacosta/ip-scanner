# 🌐 IP Scanner

## 📖 Sobre o Projeto

Projeto desenvolvido para praticar conceitos de redes de computadores e programação através da identificação e análise de endereços IP.

## 🎯 Objetivos

- Praticar lógica de programação
- Trabalhar com conceitos de redes
- Identificar dispositivos em rede
- Analisar endereços IP

## 🚀 Tecnologias Utilizadas

- Git
- GitHub

## ✅ Funcionalidades

- Verificação de IP
- Análise de conectividade
- Exploração de conceitos de rede

## 📚 Aprendizados

- Redes de Computadores
- Endereçamento IP
- Lógica de Programação
- Estruturação de Projetos
